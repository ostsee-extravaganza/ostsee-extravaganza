# Fonts

Self-hosted so the site makes zero external requests.

- **Oswald** — variable 400–700. Display / poster headlines. SIL Open Font License 1.1.
- **Work Sans** — variable 400–600 + italic. Body text. SIL Open Font License 1.1.

Both retrieved from the Google Fonts static host as woff2, `latin` and `latin-ext`
subsets (covers ä ö ü ß and the Scandinavian/Polish place names).
OFL full text: https://openfontlicense.org/
